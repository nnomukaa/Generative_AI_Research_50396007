# Generative AI Research

## Project Overview

This repository contains research materials for the study **"Using Generative AI Tools - Boon or Bane."** It includes literature, quantitative and qualitative research data, analysis files, reports, and other supporting materials.

## Repository Structure

- `01_Literature_Review/` - Journal articles, conference papers, books, and other literature.
- `02_Quantitative_Analysis/` - Survey data, Python scripts, and quantitative analysis reports.
- `03_Qualitative_Analysis/` - Interview transcripts, interview protocols, consent forms, analysis reports, and visualisations.
- `04_Drafts_and_Reports/` - Research proposals, draft papers, and final reports.
- `05_Additional_Materials/` - Information sheets, images, and other supporting materials.

## File Naming Convention

Files use descriptive and consistent names. Dates are written in `YYYYMMDD` format and version numbers are used where appropriate.

Example:

`20260918_Interview_Transcript_P001_v01.docx`

Literature articles use:

`Author_Year_ShortTitle.pdf`

## Collaboration Guidelines

1. Pull the latest version of the repository before making changes.
2. Use clear and consistent file names.
3. Use a separate branch when making significant changes.
4. Write meaningful commit messages that describe the changes made.
5. Review changes before merging them into the main branch.
6. Do not upload sensitive or confidential participant information to the public repository.
